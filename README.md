# WhatsApp AI бот — бизнестерге арналған

Клиенттердің WhatsApp-тағы сұрақтарына тәулік бойы, қазақша және орысша жауап беретін бот.
Бір сервер бірнеше бизнеске қызмет көрсетеді: әр бизнестің өз ақпараты, өз нөмірі бар.

**Негізгі қағида: бот ойдан шығармайды.** Жауап тек бизнестің `knowledge.txt` файлынан алынады.
Ақпарат жоқ болса, бот нөмірді береді және иесіне Telegram арқылы хабарлайды.

---

## Қалай жұмыс істейді

```
Клиент WhatsApp-қа жазады
        │
        ▼
Meta Cloud API ──► POST /webhook  (қолтаңба тексеріледі, қайталанғаны сүзіледі)
                        │
                        ▼
              phone_number_id бойынша бизнес анықталады
                        │
     ┌──────────────────┼─────────────────────────────┐
     ▼                  ▼                             ▼
 Сәлем/рахмет      "Адаммен сөйлесем"          Басқа сұрақ
 (AI-сыз, тегін)   → адамға беру                     │
                                                     ▼
                                         RAG: knowledge.txt-тен 3 жақын бөлік
                                                     │
                                     жақын бөлік жоқ? ── иә ──► "ақпарат жоқ" + иесіне хабар
                                                     │ жоқ
                                                     ▼
                                     Claude: тек осы бөліктер бойынша жауап
                                     (білмесе [[HANDOFF]] → адамға беру)
                                                     │
                                                     ▼
                                          Клиентке WhatsApp жауабы
```

## Құрылым

| Жол | Не істейді |
|---|---|
| `businesses/<id>/config.yaml` | Бизнес баптауы: атауы, нөмірі, сәлемдесу мәтіні, қосымша ережелер |
| `businesses/<id>/knowledge.txt` | AI боттың білетін барлық ақпараты (mode: ai) |
| `businesses/<id>/menu.yaml` | Базалық боттың мәзірі (mode: menu) |
| `app/main.py` | WhatsApp webhook сервері (FastAPI) |
| `app/brain.py` | AI бот: сәлемдесу, адамға беру, RAG, Claude |
| `app/menu.py` | Базалық бот: мәзір, батырмалар, формалар (AI-сыз) |
| `app/rag.py` | Мәтінді бөлу, векторлау, іздеу (ChromaDB) |
| `app/whatsapp.py` | Meta API: қолтаңба, хабарлама оқу және жіберу |
| `app/ycloud.py` | YCloud API: қолтаңба, хабарлама оқу және жіберу, иесінің хабарлары (echo) |
| `app/store.py` | Әңгіме тарихы, қайталанған хабарламаларды сүзу (SQLite) |
| `app/notify.py` | Иесіне Telegram хабарлары: 🟢 өтінім, 🔔 адам керек |
| `scripts/build_index.py` | Білім базасын құру |
| `scripts/chat_cli.py` | WhatsApp-сыз терминалда сөйлесу (демо, баптау) |
| `scripts/run_eval.py` | Сапа тесті және дәлдік есебі |
| `scripts/e2e_check.py` | Толық жүйе тесті (интернетсіз, кілтсіз) |
| `eval/<id>.yaml` | Тест сұрақтары |
| `tests/` | Автоматты тесттер (API кілтсіз) |

Бизнестер: `aru-salon` (сұлулық салоны) және `tulpar-auto` (автосервис) — ойдан шығарылған демо;
`zhas-bot` — сенің өз қызметіңнің (JasaBot) боты: бизнес иелерінің «WhatsApp бот» туралы сұрақтарына жауап береді
(бағалар мен шарттарды `businesses/zhas-bot/knowledge.txt` ішінде өзің түзет).

## 1-қадам. Компьютерге орнату (Windows)

```
cd whatsapp-ai-bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Орнату бірнеше минут алады (torch кітапханасы үлкен). Содан кейін:

1. `.env.example` файлын көшіріп, атын `.env` деп өзгерт.
2. Ішіне `ANTHROPIC_API_KEY` жаз (console.anthropic.com). WhatsApp кілттерін 3-қадамда толтырасың.

Тесттерді тексер (API кілтсіз жұмыс істейді):

```
python -m pytest -q              # unit-тесттер
pip install scikit-learn
python -m scripts.e2e_check                    # толық жүйе тесті, Meta режимі
python -m scripts.e2e_check --provider ycloud  # толық жүйе тесті, YCloud режимі
```

Кодты өзгерткен сайын екеуін де іске қос. `e2e_check` бір рет нақты қатені тапқан:
Anthropic API-дің 2026-10-21 нұсқасы `temperature` параметрін қабылдамайды — оны сұранысқа қоспа.

## 2-қадам. Терминалда сөйлесіп көру

```
python -m scripts.build_index
python -m scripts.chat_cli aru-salon --debug
```

Алғаш рет embedding моделі жүктеледі (~470 МБ). `--debug` әр сұраққа табылған бөліктер мен
қашықтықты көрсетеді: ✓ — шектен өтті, ✗ — өтпеді.

Сұрап көр: «Маникюр қанша?», «Жексенбі ашықсыздар ма?», «Ботокс бар ма?», «Сколько стоит стрижка?»

### Ұқсастық шегін (MAX_DISTANCE) баптау

```
python -m scripts.run_eval aru-salon --retrieval-only
```

Скрипт жауабы бар және жоқ сұрақтардың қашықтығын салыстырып, шекті ұсынады.
Сол мәнді `.env` ішіндегі `MAX_DISTANCE`-ке жаз.

## 3-қадам. Meta WhatsApp баптау

Meta интерфейсі уақыт өте өзгеруі мүмкін, бірақ негізгі қадамдар бірдей:

1. **developers.facebook.com** → My Apps → **Create App**. WhatsApp-қа арналған түрін таңда, Business портфолиосын байланыстыр.
2. Қолданбаның ішінде **WhatsApp → API Setup** бетін аш:
   - Meta тегін **тест нөмірін** береді.
   - **Phone number ID** көшіріп, `businesses/aru-salon/config.yaml` ішіндегі `phone_number_id`-ге қой.
   - **Temporary access token** көшіріп, `.env` ішіндегі `WHATSAPP_ACCESS_TOKEN`-ге қой (24 сағат жарамды).
   - «To» тізіміне өз телефон нөміріңді қосып, кодпен растап ал.
3. **App settings → Basic → App secret** көшіріп, `WHATSAPP_APP_SECRET`-ке қой.

## 4-қадам. Серверді іске қосу және webhook

Бірінші терминалда:

```
uvicorn app.main:app --port 8000
```

Екінші терминалда ngrok (ngrok.com, тегін) — компьютеріңді интернетке уақытша ашады:

```
ngrok http 8000
```

ngrok берген `https://...ngrok-free.app` адресін көшір. Meta-да **WhatsApp → Configuration → Webhook**:

- **Callback URL:** `https://...ngrok-free.app/webhook`
- **Verify token:** `.env` ішіндегі `WHATSAPP_VERIFY_TOKEN` мәні
- **Verify and save** бас, содан кейін **Webhook fields** ішінде `messages` өрісіне жазыл (Subscribe).

Енді телефоныңнан тест нөміріне «Сәлем» деп жаз. Бот жауап беруі керек.
Сервер терминалында әр хабарлама туралы жол шығады.

## YCloud арқылы қосу (Coexistence: нөмір мен WhatsApp Business қосымшасы сол күйі қалады)

YCloud — Meta-ның ресми серіктесі. Тегін тарифінде 2 нөмір қосуға болады, Meta хабарламаларына үстеме қоспайды.
Coexistence арқылы бизнес иесі барлық әңгімені өз телефонындағы WhatsApp Business қосымшасынан көреді.
**Иесі клиентке өзі жазса, бот сол чатта `OWNER_PAUSE_HOURS` сағат (әдепкі 6) үндемейді** — екеуі қатар жазбайды.

1. **ycloud.com**-да тіркел (Free тариф).
2. **WhatsApp accounts** → қосу → **Coexistence** таңда (Facebook арқылы немесе QR код арқылы).
   Бизнес туралы мәліметті толтырып, телефондағы WhatsApp Business қосымшасымен QR кодты сканерле.
   JasaBot үшін жеке нөміріңді емес, бөлек SIM-карта қолдан.
3. **Developers** бөлімінен **API key** алып, `.env` ішіндегі `YCLOUD_API_KEY`-ге жаз.
4. Серверді және ngrok-ты қос (4-қадамдағыдай). YCloud → **Developers → Webhook → Add Endpoints**:
   URL: `https://...ngrok-free.app/webhook`, оқиғалар: `whatsapp.inbound_message.received`
   және иесінің хабарлары үшін echo оқиғалары (тізімде бар болса). Берілген **secret**-ті `YCLOUD_WEBHOOK_SECRET`-ке жаз.
5. `businesses/zhas-bot/config.yaml` ішіндегі `whatsapp_number`-ге нөмірді жаз (мысалы `"+77001234567"`).
6. `.env` ішінде `PROVIDER=ycloud` қойып, серверді қайта қос.
7. Басқа телефоннан JasaBot нөміріне жаз — бот жауап беруі керек. Сосын WhatsApp Business қосымшасынан
   сол клиентке өзің жаз — бот сол чатта үндемеуі керек.

Ескертулер:
- Иесінің хабарлары қай оқиға атауымен келетінін алғашқы нақты тексеруде нақтыла: сервер логында
  `YCloud оқиғасы өткізілді: ...` деген жол шықса, сол атауды маған жібер.
- YCloud режимінде клиентке «оқылды» (көк құсбелгі) белгісі жіберілмейді.
- 1000-нан асқан хабарлама ақысы мен төлем тәсілін YCloud-тың Billing бетінен тексер.
- Meta бизнесті тексеруден өтуді сұрауы мүмкін.

### Жаңа клиент: өзінің тегін YCloud аккаунты (бізге шығыны 0 ₸)

Әр клиент YCloud-та өз атынан (өз поштасымен) тегін аккаунт ашады. Нөмір мен клиенттер базасы
клиенттің атында қалады, 1000-нан асқан хабар ақысын клиент өз әмиянынан төлейді.
Қолмен жасайтын жұмыстың бәрін сен істейсің, клиент тек Facebook-қа кіріп, QR кодты сканерлейді (≈10 минут).

1. Клиентпен бірге: ycloud.com → тіркелу (клиенттің поштасы) → Coexistence арқылы нөмірін қосу (жоғарыдағы 2-қадам).
2. Сол аккаунттың **API key**-ін және webhook **secret**-ін (URL дәл сол: `.../webhook`) сенің `.env` файлыңа жаз.
   Атауы — клиенттің қысқа аты, мысалы салон «Ару» үшін `ARU`:
   ```
   YCLOUD_API_KEY_ARU=...
   YCLOUD_WEBHOOK_SECRET_ARU=...
   ```
3. Клиенттің `businesses/<id>/config.yaml` файлына:
   ```yaml
   whatsapp_number: "+77001234567"
   ycloud_account: aru        # .env-тегі _ARU бөлігі
   ```
4. Серверді қайта қос. Кілт жетіспесе, сервер қосылмай, қай бизнеске не жетіспейтінін жазады.

`ycloud_account` жазылмаған бизнестер сенің өз аккаунтыңды (`YCLOUD_API_KEY`) қолданады.
Қауіпсіздік: бір аккаунттан басқа бизнестің атынан келген хабарға бот жауап бермейді.

## 5-қадам. Сапаны өлшеу (клиентке тапсырмас бұрын)

```
python -m scripts.run_eval aru-salon
```

Әр сұраққа ✅/❌ шығады, соңында **ДӘЛДІК** пайызы. Есеп `data/eval_aru-salon.csv`
файлына жазылады, Excel-де ашылады. Мұны клиентке «бот 50 сұрақпен тексерілді, дәлдігі 96%» деп көрсет.

❌ шыққанда:
- Жауап дұрыс, бірақ тест өтпеді → `eval/*.yaml` ішіндегі `must_contain`-ді түзет.
- Бот білмеді → `knowledge.txt`-ке ақпарат қос, `build_index` қайта іске қос.
- Бот ойдан шығарды → `MAX_DISTANCE`-ті азайт немесе `config.yaml` ішіндегі `extra_rules`-ке ереже қос.

## Базалық бот (mode: menu) — AI-сыз, Claude шығыны жоқ

Бизнестің `config.yaml` ішінде `mode: menu` болса, бот мәзір мен батырмалармен жұмыс істейді:
клиент батырманы басады (немесе нөмірін, атауын жазады), бот дайын жауапты жібереді.
Claude API кілті керек емес. Қазір `zhas-bot` осы режимде, `aru-salon/menu.yaml` — салонға дайын үлгі.

Мәзір `businesses/<id>/menu.yaml` файлында (үлгісін `app/menu.py` басындағы сипаттамадан қара):

- `items` — батырмалар (атауы ≤ 20 таңба). Ішінде `items` болса — ішкі мәзір, `answer` — дайын жауап.
- `also` — жауаптан кейін қосымша батырма (мысалы, бағадан кейін «✍️ Жазылу»).
- `action: form` — сұрақ-жауап формасы (жазылу, өтінім). Соңында иесіне 🟢 ЖАҢА ӨТІНІМ барады.
- `action: human` — адамға беру.
- Клиент «мәзір», «меню» немесе «0» деп жазса — басты мәзірге оралады.
- 3 нұсқаға дейін — WhatsApp батырмалары, 4–10 нұсқа — тізім.

Мәзірді өзгерткен соң серверді қайта қосудың қажеті жоқ: файл өзгергенін бот өзі байқайды.
Терминалда тексеру: `python -m scripts.chat_cli zhas-bot` (немесе Windows-та `TRY_ZHAS_BOT.bat` екі рет бас).
AI тарифіне ауысу: `mode: ai` қойып, `ANTHROPIC_API_KEY` жаз, `python -m scripts.build_index`.

## Өтінімдер: бизнес иесі клиент туралы қалай біледі

Бот иесіне Telegram арқылы екі түрлі хабар жібереді:

- **🟢 ЖАҢА ӨТІНІМ** — клиент жазылғысы, сатып алғысы немесе қосылғысы келеді («Ертең 15:00-ге маникюрге жазылайын»).
- **🔔 АДАМ КЕРЕК** — бот жауабын білмеді немесе клиент адаммен сөйлескісі келеді.

Әр хабарда: клиенттің аты мен нөмірі (WhatsApp өзі береді), бүкіл әңгіме және `https://wa.me/...` сілтемесі —
иесі оны басып, клиентке бірден WhatsApp-та жаза алады. Тақырыптан тыс сұрақтарда иесі мазаланбайды.

**Баптау (бір рет, 5 минут):**

1. Telegram-да **@BotFather** → `/newbot` → атын беріп, **токенді** ал. Оны `.env` ішіндегі `TELEGRAM_BOT_TOKEN`-ге жаз.
   Бір хабарлаушы бот барлық бизнеске жетеді.
2. Бизнес иесі (немесе сен) осы ботты ашып, **Start** басады және кез келген сөз жазады.
3. Браузерде `https://api.telegram.org/bot<ТОКЕН>/getUpdates` аш. Жауаптағы `"chat":{"id": ...}` санын көшір.
4. Оны сол бизнестің `config.yaml` ішіндегі `telegram_chat_id`-ге жаз. Әр бизнес иесі тек өз клиенттерін көреді.
   Салонда бірнеше әкімші болса: Telegram топ ашып, ботты топқа қос — топтың id-і минуспен басталады.
5. Тексеру: ботқа WhatsApp-та «Ертең маникюрге жазылғым келеді» деп жаз — Telegram-ға өтінім келуі керек.

Бот жазылуды өзі растамайды: «әкімші растайды» дейді. Иесі уақытты тексеріп, клиентке өзі жазады.

## Жаңа бизнес (клиент) қосу

1. `businesses/aru-salon` папкасын көшір, атын өзгерт (мысалы `businesses/dana-clinic`).
2. `config.yaml`: `id`, `name`, `phone_number_id`, `contact_phone`, `greeting`, `extra_rules`.
3. `knowledge.txt`: бизнестің барлық ақпараты. Әр тақырып — бөлек абзац (арасы бос жол).
   Бизнес иесінен сұрайтындар: қызметтер мен бағалар, жұмыс уақыты, мекенжай, төлем, жазылу тәртібі, жиі сұрақтар.
   Клиенттері орысша да жазса, соңына қысқа «Кратко на русском» абзацын қос (негізгі баға, уақыт, шарттар).
   Нақты тексеруде бұл орысша сұрақтардың қашықтығын 0.22-ден 0.11–0.20-ға түсірді.
4. `eval/<id>.yaml` — кемінде 50 сұрақ (оның 10–15-і құжатта жоқ сұрақтар).
5. `python -m scripts.build_index <id>` және `python -m scripts.run_eval <id>`.

## Серверге орналастыру (Docker)

```
docker build -t whatsapp-bot .
docker run -d --name bot --env-file .env -p 8000:8000 -v bot-data:/bot/data whatsapp-bot
```

VPS-та домен және HTTPS керек (мысалы Caddy немесе Nginx арқылы). Webhook адресін ngrok-тан
тұрақты доменге ауыстыр. Тұрақты жұмыс үшін Meta Business Manager-де **System User** жасап,
мерзімі шектелмеген токен ал.

## Маңызды ережелер мен шығындар

- **Meta AI ережесі:** жалпы мақсаттағы AI чат-боттарға (ChatGPT сияқты) WhatsApp-та тыйым салынған.
  Бизнестің өз клиенттеріне қызмет көрсететін бот рұқсат етілген. Сондықтан промптта бот тек
  сол бизнес тақырыбына жауап беретіні жазылған — бұл ережені алып тастама.
- **WhatsApp төлемі (Қазақстан, 2026 жылғы 1 қазаннан):** бір нөмірге айына 1 000 қызмет хабарламасы тегін,
  одан әрі әрқайсысы шамамен $0,018. Төлемді бизнес Meta Billing Hub-та өз картасымен төлегені дұрыс.
  Ағымдағы бағаны Meta-ның ресми бетінен тексер.
- **Шығынды азайту:** сәлемдесу мен алғысқа AI шақырылмайды; бір сұраққа бір хабарлама жіберіледі.
- **Жеке деректер:** клиент нөмірі мен хабарламалары `data/bot.sqlite3`-те сақталады, 30 күннен кейін
  автоматты өшіріледі. Бизнеспен жасалатын шартта бұны жаз.
- **Құпия кілттер:** `.env` файлы `.gitignore`-да тұр. Оны ешқашан GitHub-қа салма.
